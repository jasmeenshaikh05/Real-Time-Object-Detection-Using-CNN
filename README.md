# PantherAI - Intelligent Object Detection System

PantherAI is an AI-powered real-time object detection and monitoring platform built using Python, Flask, OpenCV, and YOLO. The system detects objects from image, video, or live camera streams, generates alerts, logs detection events, and provides a dashboard for monitoring and analytics.

## Features

- Real-time object detection using YOLO
- Flask-based backend API
- Interactive monitoring dashboard
- Alert generation system
- Detection event logging
- Model management and training modules
- Stream processing support
- Dataset management utilities
- Modular and scalable architecture

## Tech Stack

- Python
- Flask
- OpenCV
- YOLO
- HTML/CSS/JavaScript
- REST APIs

## Project Structure

- `api/` - API endpoints
- `backend/` - Core backend services
- `dashboard/` - Monitoring dashboard
- `alerts/` - Alert management system
- `training/` - Model training utilities
- `streams/` - Video stream processing
- `models/` - Detection models
- `utils/` - Helper functions
